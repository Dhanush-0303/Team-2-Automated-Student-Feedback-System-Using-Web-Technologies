# Automated Student Feedback System Using Web Technologies

A team project exploring how web forms and HTTP methods can be used to collect student feedback.

## Overview

The project demonstrates core web-development concepts, including HTML forms and GET/POST requests, in the context of a student feedback workflow.

## Learning Objectives

- Build HTML forms to collect user feedback.
- Understand the role of GET and POST in HTTP communication.
- Explore how a browser submits form data to a web application.
- Practise organizing a small web-development project.

## Technologies

- HTML
- Web forms
- HTTP GET and POST methods

Refer to the source files for the exact implementation and any additional technologies used.
